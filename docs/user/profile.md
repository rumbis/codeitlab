# Your profile

CodeItLab asks two things about you: the **interest domain** you want the work
to be about, and the **skillset** you can already rely on. Both are optional and
both are written by you.

## What it is used for

- Starting a bot chat adds a short block labelled _Who this work is for_ to that
  bot's brief, so the agent knows whether it is talking to a designer, a founder,
  or another engineer without you repeating it every time.
- Ordinary threads do not inject it automatically; you still control what each
  conversation receives.
- The same lines are what you paste into a marketplace job brief. The app never
  sends them anywhere on its own.

## What it is not

- It is not inferred from your files, your chats, or your provider account.
- It is not uploaded. The profile lives in the CodeItLab settings on this
  machine, and an agent only sees it when a brief includes it.
- An empty field is simply left out. There is no score, no completeness meter,
  and no penalty for leaving it blank.

## Where to find it

Settings → CodeItLab → **Profile**. The page shows the exact lines an agent would
receive underneath the fields, so the wording is not a mystery.

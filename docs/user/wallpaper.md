# Wallpaper

**Settings → CodeItLab → Wallpaper** puts opt-in artwork behind the app chrome. It is off by
default.

## Options

- **Presets** — Dusk, Aurora, Grid and Paper, each shown with a swatch.
- **Custom image** — any `https://` image URL. A custom wallpaper needs a URL before it shows,
  and the page says so instead of leaving you with a blank preview.
- **Opacity** — 0–60%. The cap is deliberate: artwork should never fight the interface.
- **Apply / Turn off** — the setting is applied immediately and remembered per environment.

## Why text stays readable

While a wallpaper is on, the sidebar and the main card turn translucent over a blur, so text
always sits on a solid backing. Contrast therefore does not depend on the image you choose, and
a busy photograph cannot make the composer unreadable.

The layer itself has no animation, so there is nothing to disable for reduced motion; turning
the wallpaper off removes the layer entirely.

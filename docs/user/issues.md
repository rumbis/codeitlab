# Issues

**Settings → CodeItLab → Issues** is a small local issue list for the problems you meet while
working. It is deliberately offline: nothing is fetched, nothing is synced, and no GitHub
connection sits behind the page. A real tracker sync would need a network call and a token, so
this page says "local only" instead of implying one.

## What you can do

- **Add an issue** with a short title; details, steps and an optional source link go in the
  fields below it.
- **Status** — open, in progress, closed. Closed issues stay visible, so the history is not lost.
- **Add to board** creates a Pending task with the issue body and source in its notes.
- **Send to thread** opens a draft thread in your most recent project with a brief that asks the
  agent to reproduce the problem first, keep the change scoped, and say what it could not verify.

## Why local first

The point of this surface is to catch a problem at the moment you notice it, without a network
round-trip or a token. When you want it to become work, one click puts it on the board or into a
thread — both already have a real execution path.

## Keyboard

Enter in the issue title field adds the issue, so a quick note does not need a
pointer. Each issue's board and thread actions are buttons with the same
keyboard behaviour as a click.
